PROJECT OVERVIEW:
Build and maintain an end-to-end, zero-trust AI Document Screening and KYC Verification
platform designed for government and enterprise security audits (Smart India Hackathon).
The system must automatically ingest Indian identity documents (Aadhaar, PAN, Passport,
Voter ID, Driving License), detect digital image forgeries, verify algorithmic checksums,
and execute biometric facial comparison against live selfies.

KEY CORE MODULES & ALGORITHMS:

1. AADHAAR VERHOEFF CHECKSUM (services/validation.py):
   - Implements the Dihedral Group D5 multiplication table, permutation matrix, and inverse table.
   - Validates whether a 12-digit number sequence is authentic according to UIDAI standard.
   - Flag any mathematical mismatch as critical fraud.

2. PAN CARD ENTITY & SURNAME LOGIC (services/validation.py):
   - Structure: 5 letters, 4 digits, 1 check letter.
   - 4th character defines entity type (P for Individual, C for Company, F for Firm, etc.).
   - 5th character for individual PAN ('P') must match the first letter of cardholder's surname.

3. ERROR LEVEL ANALYSIS - ELA (services/tamper.py):
   - Re-compress image at JPEG quality 90 to an in-memory buffer.
   - Calculate absolute pixel difference: cv2.absdiff(original, recompressed).
   - Scale difference (x20) and render JET colormap heatmap.
   - Identify spliced patches and foreign noise distributions.

4. BIOMETRIC FACE VERIFICATION & LIVENESS (services/face.py):
   - Isolate face region from document photo.
   - Extract face from live webcam selfie.
   - Calculate HSV color histogram correlation, template cross-correlation, and structural edges.
   - Run 2D FFT frequency spectrum check for screen moiré patterns (detects replay attacks).

5. COMPOSITE RISK ENGINE (services/risk.py):
   - Fuses OCR confidence (20%), Checksums (30%), ELA forensics (30%), Biometrics (20%).
   - Tiers: LOW_RISK (<30) -> APPROVE, MEDIUM_RISK (30-65) -> MANUAL REVIEW, HIGH_RISK (>65) -> REJECT.

6. TRUSTLENS AI COPILOT (services/chatbot.py):
   - Contextual fraud investigator assistant powered by Gemini 2.5 Flash / offline rule engine.
   - Answers inquiries on ELA heatmaps, Verhoeff mathematics, and KYC compliance.
